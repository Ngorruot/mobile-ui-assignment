# CPRG303 Mobile UI Assignment

## Ngor Profile App

This project is a mobile user interface developed using React Native, Expo, and TypeScript for the CPRG303 Mobile Application Development course at SAIT.

The application recreates a social media group profile inspired by Instagram.

## Features

- profile displaying the name OOTD Everyday.
- Username: @ootd_everyday.
- Profile statistics showing 53 posts, 12 members, and 1 admin.
- biography and description.
- Three-column photo grid displaying nine images.
- Interactive Member button that displays a membership alert.
- Interactive Alert button.
- Bottom navigation icons.
- Scrollable profile screen.

## Technologies Used

- React Native
- Expo
- TypeScript
- Expo Router
- React Native StyleSheet

## How to Run the Application

### 1. Install dependencies

```bash
npm install
```

### 2. Start the application

```bash
npx expo start
```

### 3. Open the application

Scan the QR code using Expo Go on your mobile device.

## Project Structure

- `src/app/index.tsx` — Main group profile screen.
- `src/app/_layout.tsx` — Application layout.
- `assets/posts/` — Images displayed in the photo grid.
